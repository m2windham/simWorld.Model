# simWorld.Model — LLM → Blender asset pipeline for simWorld.Host

Two layers live here, after the Oct 2026 drive loss:

- **The original pipeline** (`run_pipeline.py`, `pipeline/`, `orders/*.md`, `README.md`, `GEMINI.md`,
  `NATURAL_ROCK_NOTES.md`): reconstructed from Antigravity transcripts at high confidence
  (manifest in `H:\dev\_recovery\extracted\simWorld.Model\_RECOVERY_MANIFEST.md`). It produced every
  shipped asset and defines the aesthetic standard (Timberborn-inspired stylized realism, PBR,
  micro-bevels; see `orders/MANIFEST.md`). Generators live in `pipeline/generators/`, QA in
  `pipeline/qa/`, refinery (PBR bake, UV, normals, collision) in `pipeline/refinery/`.
- **`swm/`** — the thin gate added 2026-10-05: TOML orders + `recipes/` for quick deterministic
  builds, the combined-triangle budget check, Workbench snapshots, and `deliver` into the Host with
  the Host's own instruments. Use it for gating and delivery regardless of which layer built the FBX.

Nothing is generated by an external 3D service; the LLM writes bpy code and Blender builds it.

## Layout

- `orders/<DefName>.toml` — swm orders (defName, family = budget class, recipe, 4 variants, seed, size, style, material). `orders/*.md` are the original pipeline's order documents.
- `recipes/<name>.py` — swm recipes: `build(ctx) -> bpy Object`, deterministic from `ctx.rng`; swm does origin, budget, shading, material, collision, export.
- `swm/blender_build.py` / `swm/blender_snapshot.py` run inside background Blender; `swm/run.py` is the `swm` CLI.
- `out/<DefName>/` — swm builds (gitignored); `output/` — the original pipeline's output tree.
- `../simWorld.Host` and `../simWorld` must be siblings (the Host's tools resolve the core relatively).

## Commands

```
uv run swm build CollapsedRocks            # Blender -b build, prints tris per variant, fails on sourced budget
uv run swm snapshot CollapsedRocks --ref Sandstone_a --ref ChunkGranite_a   # Workbench contact sheet
uv run swm deliver CollapsedRocks          # copy into Host/Assets/Resources/Models + run Host checks
uv run swm preview CollapsedRocks          # open variants in interactive Blender
```

Blender is `H:\tools\Blender\blender.exe` (override with `BLENDER_PATH`). For interactive recipe work use the `blender` / `blender-lab` MCP servers with Blender 5.2 open.

## The Host contract (do not break)

- File `<defName>_a..d.fbx`, exactly 4 variants; the Host picks a variant by thing id.
- `defName` must be a `ThingDef` in `SimWorld.Core` or nothing draws it (`Host/tools/check_defnames.py`).
- One grid cell = 1 unit; origin at footprint centre, mesh resting on z = 0; Sandstone_a is 1×1×1.
- Each file: visual mesh `<Name>` with material `M_<Name>_PBR`, plus convex collision `UCX_<Name>_01`.
- Budgets (`Host/docs/triangle-budget.md`) count **visual + UCX together**: scatter 400 (sourced, fails), item 400, ore 1200, dwelling 2500 (proposed). New scatter families also need a prefix entry in `Host/tools/measure_triangles.py` `BUDGETS`.
- `check_defnames.py` currently exits 1 because of the four parked `House_*` families; that is a known, accepted state.

## Adding a family

1. Write `orders/<DefName>.toml`; pick or write a recipe.
2. `swm build`, then `swm snapshot` with a Host reference and look at the PNG before judging it done.
3. `swm deliver`; stage in the Host but do not commit without Doug.
